# CheckerDiscount - Financial Monitoring Tool

High-trust, ad-free deal & refund tracking application built on Cloudflare serverless stack.

## Tech Stack
- **Frontend:** Cloudflare Pages (HTML5, CSS3, Vanilla JS)
- **Backend API:** Cloudflare Workers (`checkerdiscount-api`)
- **Database:** Cloudflare D1 (SQLite Engine)
